# Contributing to Lucid Drift

Thank you for your interest in Lucid Drift!

Lucid Drift is an experimental 2D game engine and editor written in modern C++. Contributions, testing, bug reports, and technical discussions are welcome.

## Areas Where Help Is Welcome

Contributors can help with:

- Windows support, including MSVC and CMake.
- OpenGL rendering and shader improvements.
- Geometry and polygon triangulation.
- Scene and object management.
- Testing and bug fixes.
- Documentation and build instructions.

## Before Starting

1. Check the existing Issues to see whether the task has already been reported.
2. For significant changes, open an Issue first to discuss the proposed approach.
3. For an existing Issue, leave a comment before starting work so that duplicate efforts can be avoided.

## Development Guidelines

- Keep changes focused on one issue or feature.
- Follow the existing C++ code style where practical.
- Avoid unrelated formatting or refactoring changes.
- Do not include build directories, generated binaries, or IDE-specific files in commits.
- Include relevant build and test information in pull requests.

## Pull Requests

When submitting a pull request, please include:

- A clear explanation of the changes.
- The Issue number, if applicable.
- The operating system, compiler, and CMake version used for testing.
- Build or test results.
- Screenshots for changes involving the editor or rendering.

## Project Status

Lucid Drift is experimental and under active development. Some APIs and systems may change, and not every subsystem is production-ready.

Thank you for helping Lucid Drift grow!
